UAT uplink transport: bench results (PR #289)

Wire formats

WebSocket ws://<device>/uplink, one binary message per uplink (440 bytes):
  0..431  payload (8 byte UAT header + 424 bytes application data)
  432     RSSI, int8 dBm (-128 = unknown)
  433..435 reserved, zero
  436..439 timestamp, uint32 little endian, ms since boot

Serial, AT+PROTOCOL_OUT=<interface>,AIRCRAFT_JSON_UAT_UPLINK, one line per uplink:
  {"uat_uplink":"NRTJUtZcurAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA...AAAAAAAAAAAAAAAA","rssi":-91,"t":578033}
